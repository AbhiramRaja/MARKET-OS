# MarketOS Portal (Consumer) - Starter

This workspace contains a starter scaffold for the MarketOS consumer portal (React + Tailwind).

Quick start (macOS / zsh):

1. cd into the project
2. npm install
3. npm start

Notes:
- This scaffold includes routing, Tailwind setup, basic Header/Footer, Auth and Cart context stubs, and mock services.
- AWS Amplify / Cognito / S3 integration steps are documented in the TODO list and will be added next.
