## 🐛 IF SOMETHING GOES WRONG:

### **Portal Won't Start:**
```bash
./stop-demo.sh
./start-demo.sh
```

### **Product Doesn't Sync:**
```
Hard refresh Customer Portal: Ctrl+Shift+R (or Cmd+Shift+R on Mac)
```

### **Order Fails:**
```
Check console (F12) for errors
Verify user is logged in
Try refreshing page
```

### **Visual Search Fails:**
```
Use smaller images
Try different file format
Check console for errors
Fall back to regular search
```
